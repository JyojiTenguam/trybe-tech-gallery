# 🖼️ Trybe Tech Gallery

Exercício focado na criação de uma galeria de imagens interativa, com JavaScript, permitindo o filtro e a navegação entre as imagens de uma galeria de forma dinâmica.

## ✨ Demonstração

> A aplicação exibe uma galeria de imagens, com a funcionalidade de filtro e navegação entre elas, proporcionando uma interação dinâmica com o usuário.

## 💡 Sobre

Este exercício visa a construção de uma galeria de imagens interativa. O projeto permite filtrar as imagens por categoria e visualizar uma imagem maior ao clicar nela. O foco foi aplicar conceitos de manipulação de DOM e eventos com JavaScript.

## 🛠️ Habilidades desenvolvidas

- Manipulação do DOM com JavaScript
- Criação de filtros dinâmicos de imagens
- Navegação interativa entre elementos
- Utilização de eventos para interação do usuário

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6+
